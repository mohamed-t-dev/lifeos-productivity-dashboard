# LifeOS Productivity Dashboard

A self-contained planning interface that explores daily task management, weekly organization, progress visibility, and responsive productivity workflows.

> Portfolio concept: LifeOS is a front-end demonstration. Tasks and settings remain local to the browser experience and are not synchronized with a production account.

## Highlights

- Daily and weekly planning views
- Task creation and completion interactions
- Responsive layouts for desktop and smaller screens
- Progress and review states
- Self-contained HTML, CSS, and JavaScript implementation
- Static deployment configuration

## Technology

- HTML
- CSS
- JavaScript

## Run locally

Serve `index.html` using any local static server.

## Project status

Portfolio demonstration. The repository intentionally contains only the published planner experience.
